# Meyar Financial Platform

Financial market platform for tracking gold, currency and market data.

## Features

- Gold and currency price tracking
- Market history API
- Admin dashboard
- AI chat assistant
- Price management system

## Technology

- PHP
- SQLite
- JavaScript
- CSS
